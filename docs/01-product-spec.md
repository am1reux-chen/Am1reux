# Lexio 产品规格（V1）

Lexio 是一款 Windows 原生、离线优先的智能英语背单词软件。核心价值：极简界面 + 科学间隔重复（FSRS-6）+ 个人化每日规划 + 高性能。

## 目标用户
备考（四六级/高考/IELTS/TOEFL/GRE）与日常扩充词汇的 Windows 用户。

## V1 页面（仅四个）
| 页面 | 内容 | 不做什么 |
|---|---|---|
| Today | 问候、三档强度选择（轻量 55% / 常规 100% / 重度 170% 基准负载），每档动态显示预计分钟、复习数、新词数 | 不堆图表与任务清单 |
| Learn | 沉浸式卡片流：单词→回忆→答案→评分（Again/Hard/Good/Easy，可折叠为 记得/忘记 二档） | 无强制拼写 |
| Library | 词库浏览、FTS 搜索、CSV/TXT 导入、自建词书 | 不做账号体系 |
| Insights | 记忆状态（新/学习中/复习中分布）、未来 7 天负载、当日统计 | 不做排行榜/签到 |

设置（次级入口）：目标保留率、每日基准、评分模式（4 档/2 档）、发音（美/英）、减少动态效果、备份/恢复。

## 学习交互（默认流程）
1. 显示英文单词（+音标可显隐）
2. 用户在心中回忆 → 空格/点击「显示释义」
3. 显示释义、词性、例句
4. 用户评分（默认 2 档：忘记→Again；记得→Good；高级模式 4 档）
5. 记录结果与有效思考时长 → 动画切换下一张（下一张已预加载，不等待动画）

键盘：空格=显示答案，1/2/3/4=Again/Hard/Good/Easy，E=发音，Esc=结束。
发音：Windows 内置 TTS（SpeechSynthesizer，离线）。

## 非目标（V1 明确不做）
人物养成、金币、排行榜、社区、强制签到、云端同步、多端、拼写强制模式。

## 性能目标（须实测验证，未测量前不得宣称达成）
- 冷启动到可交互 ≤ 1s
- 卡片切换无可感知等待（目标 < 16ms 交互延迟）
- 常规动画 60 FPS
- 词库搜索首批结果 ≤ 50ms（10 万词级）
- 所有数据库操作离开 UI 线程
