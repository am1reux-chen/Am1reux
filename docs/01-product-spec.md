# Lexio 产品规格

Lexio 是一款 Windows 原生、离线优先的智能英语背单词软件。核心价值：极简界面 + 科学间隔重复（FSRS-6）+ 个人化每日规划 + 高性能。

## 目标用户
备考（四六级/高考/IELTS/TOEFL/GRE）与日常扩充词汇的 Windows 用户。

## 页面
| 页面 | 内容 | 不做什么 |
|---|---|---|
| Today | 选择词书、练习方式与三档强度（轻量 55% / 常规 100% / 重度 170% 基准负载），显示预计分钟、复习数、新词数 | 不堆图表与任务清单 |
| Learn | 回忆、跟写、看义拼写、听写和自测；收藏/已掌握卡片 | 输入练习可选，不强制拼写 |
| Library | 词库浏览、FTS 搜索、CSV/TXT、TypeWords JSON 与本地 TypeWords ZIP 导入、自建词书、收藏/错词/已掌握筛选与管理 | 不做账号体系 |
| Articles | 新建、编辑、删除与导入文章；双语全文阅读、逐句跟写或听写，保存标题译文、段落译文和练习进度 | 不做在线翻译或云端文章库 |
| Insights | 记忆状态（新/学习中/复习中分布）、未来 7 天负载、当日统计 | 不做排行榜/签到 |

设置（次级入口）：目标保留率、每日基准、评分模式（4 档/2 档）、发音（美/英）、减少动态效果、备份/恢复。

## 学习交互（默认流程）
1. 显示英文单词（+音标可显隐）
2. 用户在心中回忆 → 空格/点击「显示释义」
3. 显示释义、词性、例句及已导入的短语、近义词、词源和相关词
4. 用户评分（默认 2 档：忘记→Again；记得→Good；高级模式 4 档）
5. 记录结果与有效思考时长 → 动画切换下一张（下一张已预加载，不等待动画）

键盘：空格=显示答案，1/2/3/4=Again/Hard/Good/Easy，E=发音，Esc=结束。
发音：Windows 内置 TTS（SpeechSynthesizer，离线）。

## 单词练习与标记

Today 默认使用回忆模式，也可选择跟写、看义拼写、听写或自测。输入答案会忽略首尾空格并按大小写不敏感方式比较。输错时记录 Again 和错词标记；拼写正确后继续使用当前的二档或四档 FSRS 评分。自测从同一词书生成四个不同释义选项，所选计划缺少释义或干扰项时会说明原因，不启动自测。

收藏、错词和已掌握状态保存在具体的词书卡片上。同一词出现在不同词书中，各自保留状态。错词可在 Library 筛选并清除；已掌握卡片从新词和到期计划中排除。标记不会改写 FSRS 到期时间或复习历史，取消已掌握后卡片按原计划重新参加学习。

## 文章逐句学习

Articles 支持创建、编辑、删除和导入 UTF-8 纯文本、TypeWords JSON 或用户自行选择的 TypeWords GitHub ZIP。纯文本导入时每个非空行作为一句；JSON 导入按空行切分英中段落并校验数量一致，保留标题译文；ZIP 从推荐清单中读取对应词书或文章 JSON，不解压文件，也不把第三方内容打进安装包。练习页左侧显示可滚动的双语全文并高亮当前段落，点击段落即可跳转；右侧跟写显示英文原句，听写使用 Windows 本地 TTS，两种模式都允许查看译文、前后切换或跳过。答对、跳过或跳转后先保存位置；重新打开未完成文章会恢复句序和练习方式，完成后可以从全文选择段落继续。文章进度独立于 FSRS 单词卡和复习计划。

## 非目标
人物养成、金币、排行榜、社区、强制签到、云端同步、多端、在线翻译和远程文章库。跟写、看义拼写与听写都是可选练习方式，不会替代回忆默认流程。

## 性能目标（须实测验证，未测量前不得宣称达成）
- 冷启动到可交互 ≤ 1s
- 卡片切换无可感知等待（目标 < 16ms 交互延迟）
- 常规动画 60 FPS
- 词库搜索首批结果 ≤ 50ms（10 万词级）
- 所有数据库操作离开 UI 线程
