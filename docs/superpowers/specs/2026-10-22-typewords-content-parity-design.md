# TypeWords 内容与文章阅读流程补齐设计

**日期：** 2026-10-22  
**状态：** 当前工作区已实现；Core/App Release 测试通过，最新 Release 应用已用隔离数据目录启动

## 决策

保留 Lexio 的深色 WinUI 框架、导航、FSRS 和本地数据管理。在现有原生页面中提供 TypeWords 词条数据和文章内容的导入，并补上词条详情与整篇双语文章阅读视图。

TypeWords 参考数据有明确结构：词条包含音标、多个词性释义、例句、短语、近义词、词源和关联词；文章包含标题译文、分段英文和对应译文。Lexio 当前内置词库覆盖词性和中文释义，但没有这些关联内容；当前文章练习页仅呈现活动句。

## 考虑过的方案

1. **兼容导入并扩展原生页面（选定）**：从用户本地 TypeWords JSON 文件或下载的 GitHub ZIP 导入内容；ZIP 读取推荐清单中的词书/文章文件，不解压、不打包第三方数据。Lexio 保留原生外观、数据库、计划和进度。
2. **把 TypeWords 数据直接打进安装包**：能减少首次导入步骤，但仓库代码 GPL-3.0 并不能证明其中每份词典/文章数据可随 Lexio 一起再发布，故不采用。
3. **改成 TypeWords 网页外观或嵌入网页**：展示会更像参考站点，但与保留 WinUI 原生界面的决定冲突，且不能补足现有数据模型。

## 词条内容与导入

- Library 继续支持 CSV/TXT，并增加 TypeWords 词典 JSON 和 GitHub ZIP 导入。导入数组内的有效词条进入用户词书；ZIP 以推荐清单中的词书名称创建词书。
- 映射词头、英美音标、词性释义、例句/译文、短语、近义词、词源和关联词。无效词条报告为跳过；损坏或非 UTF-8 JSON 不写入部分词条。
- `WordEntry` 增加一个有类型的可选详情载荷；存储采用单个 JSON 列，避免把只用于展示的辅助资料拆成多张表。详情为空的旧词库导入不能清除已存在的详情。
- Learn 继续保留当前卡片、输入模式与评分区；揭示后展示可用的词条详情分区。音频继续使用系统语音。
- 不把 TypeWords 下载目录或其中未经单独许可审计的词典/文章复制进 Lexio 安装包。用户选择的文件导入后成为用户本地数据。

## 文章内容与练习

- Articles 继续支持纯文本导入与逐句译文编辑，并增加 TypeWords 文章 JSON 和 GitHub ZIP 导入；ZIP 使用推荐清单中的文章书名称显示导入结果。
- 导入标题及标题译文；按空行切分英文段落，并与译文段落按顺序配对。段落数量无法配对时拒绝该文件，避免英文和译文错位。
- 忽略 TypeWords 文章中的远程音频路径和计时元数据；保留当前离线 TTS 及 Lexio 自己的进度。
- ZIP 仅识别 `public/list/recommend_word.json`、`public/list/recommend_article.json` 和清单引用的 JSON；每类必须且仅能解析一份推荐数据，ZIP 上限 64 MB、单个 JSON 上限 16 MB。歧义、缺文件或超限在写库前拒绝，并提示用户逐个导入 JSON。
- 文章练习页显示可滚动的整篇双语内容，并突出当前段落；右侧原生练习区仍负责跟写/听写、译文控制、前后切换与保存进度。点击正文段落可跳到该段继续学习。
- 标题译文和句子译文保存到本地数据库，随现有 SQLite 完整快照备份。

## 数据兼容性

- 追加迁移 9：`words.details_json` 与 `articles.title_translation`。已应用迁移 1–8 不变。
- 既有词条、FSRS 卡片、标记、会话和文章进度不重建；恢复旧备份时由现有迁移机制补齐新列。
- TypeWords 词条详情导入只更新本次文件提供的非空内容，不覆盖旧数据中更完整的词条详情。释义/音标继续使用当前增量导入规则。
- 重复导入沿用词头去重和同词书更新行为；文章导入以标题、英文段落、译文内容判断完全重复并跳过。

## 验收

1. TypeWords 词条 JSON 或 GitHub ZIP 导入后，Library 与 Learn 可检索/展示全部映射字段，重启后仍存在。
2. Library 与 Learn 为可用音标标注美式与英式；词条只有一种音标时仍显示它。
3. 缺少某些可选字段不会阻止导入；非法条目被计数跳过；坏文件不会产生半份词库。
4. 仅含词头/释义的导入不会清除已有例句、短语、近义词、词源或关联词。
5. TypeWords 文章 JSON 或 GitHub ZIP 导入保留英文段落、匹配的译文、标题及标题译文；译文缺失或数量不匹配时在写库前拒绝，不依赖远程音频。ZIP 清单数量与实际 JSON 条目数不一致时，成功提示必须显示两者。
6. 练习页始终能看到全文双语列表和当前高亮段落，点击另一段后输入和进度转到所选段落。
7. 只改文章标题或标题译文不改变已保存的句序和完成状态；改动句子内容才重置进度。
8. 完成文章后选择另一种练习方式会保留完成状态，并在重新开始时使用该方式。
9. 旧数据库迁移、完整备份/恢复和文章续学继续有效。
10. Release 构建成功；针对新导入映射、持久化及文章定位的自动化验收通过。

## 不在本轮范围

- 改写 TypeWords 的网页布局、动效、键盘引擎或在线服务。
- 自动下载词典/音频、在线翻译或内置未核实来源的文章数据。
- 将文章段落纳入 FSRS、修改现有词卡进度算法或引入新的运行时依赖。
