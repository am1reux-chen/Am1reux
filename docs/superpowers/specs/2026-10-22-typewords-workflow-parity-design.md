# TypeWords 工作流对照与 Lexio 功能扩展设计

**日期：** 2026-10-22
**状态：** 设计范围与 companion spec 已在当前工作区实现；Core/App 自动化验证通过，桌面视觉验收仍待实际运行后确认

## 目标

以工作区中的 TypeWords-master.zip 为流程参考，补上 Lexio 目前缺少的单词输入练习、单词标记和文章逐句练习，同时保留 Lexio 现有的离线优先、FSRS-6 复习调度和本地数据安全能力。

## 流程对照

| 环节 | TypeWords 参考流程 | 当前 Lexio |
|---|---|---|
| 开始学习 | 选词库，再选系统、自由、听写、默写、自测或混合流程 | Today 按词书和轻量、常规、重度计划开始会话 |
| 单词学习 | 跟写、释义拼写、朗读听写、选择题或自评；输入错误进入错词复习 | 显示单词，回忆后揭示释义，用户选择 FSRS 评分 |
| 单词管理 | 收藏、错词、已掌握；已掌握单词可跳过后续计划 | 词书导入和检索已有；没有这些单词状态 |
| 文章学习 | 选文章，逐句查看或听读，输入练习，可见译文并保存位置 | 没有文章内容和逐句练习 |
| 学习记录 | 记录单词与文章练习进度 | FSRS 日志、会话恢复、Insights 和完整 SQLite 备份已实现 |

Lexio 已有的 FSRS-6 排程、按历史耗时生成的每日计划、会话中断恢复、内置词典和完整备份是当前项目的基础能力，本设计继续沿用。

## 词汇练习设计

### 练习模式

每个学习会话在 Today 开始前选择一种模式。所选模式保存在会话记录中，暂停或进程重启后恢复原模式。

- 回忆：保留现有的单词、揭示释义和 Again/Hard/Good/Easy 评分流程。
- 跟写：显示单词，用户输入完整单词后确认。
- 看义拼写：显示词义，用户输入对应单词。
- 听写：使用 Windows 本地语音合成播放单词，用户输入单词。
- 自测：显示单词和四个释义选项；从同一词书寻找干扰项。缺少足够候选项或释义时，不启动该模式并说明原因。

输入忽略大小写并去除首尾空格。输入错误时显示正确答案、标记为错词，并将本次 FSRS 评分设为 Again；正确的跟写、看义拼写和听写继续使用当前的简化或四档评分偏好。自测答对自动记为 Good，答错记为 Again。

### 单词标记

收藏、错词和已掌握按卡片保存，因此同一单词出现在不同词书时各自保留状态。

- 收藏可在 Library 中筛选，也可在 Learn 中切换。
- 错词由输入练习的错误答案自动标记，可从错词筛选中查看、复习或手动清除。
- 已掌握卡片不进入新词或到期复习计划；标记只控制后续选卡，不修改 FSRS 状态、到期时间或历史日志。取消标记后，卡片按原状态重新参与计划。

错词标记与 FSRS 回答写入同一个事务。标记更新失败时，本次回答不留下部分提交状态。

## 文章学习设计

文章和句子使用独立数据及顺序进度，不作为 FSRS 单词卡参与每日排程。

- 新增 Articles 导航页，支持新建、编辑、删除和 UTF-8 纯文本导入。
- 导入文本按非空行拆分为句子；文章编辑器允许为每句填写可选译文。暂不提供在线翻译。
- 文章练习提供跟写和听写模式。跟写显示英文句子并要求输入；听写使用本地语音合成播放句子并要求输入。用户可查看可选译文、重播、跳过或前后切换。
- 每句完成或跳过后保存当前句序号和练习模式。重新打开文章时从上次位置继续；完成文章后可重新开始。
- 文章与句子删除采用数据库级级联；清理文章也会清理其进度。

## 数据与兼容性

- 所有 schema 变更追加为新迁移；已应用的迁移不修改。
- 第 7 版迁移增加单词标记表和学习会话模式字段；第 8 版迁移增加文章、句子和逐篇进度表。
- 恢复旧版 Lexio 备份时先应用缺失迁移，再验证完整 schema。新的必需表加入 AppDatabase 的 schema 完整性检查。
- 完整备份和自动备份使用整个 SQLite 数据库快照，新增内容随快照保存和恢复。复习历史 CSV 保持其现有用途。
- 不新增 NuGet 依赖，不引入网络必需流程、账号、云同步、在线翻译或远程文章库。

## UI 与错误处理

- Today 只增加一个会话模式选择，不改变三档计划的计算方式。
- Learn 保留当前默认回忆流程；其他模式以同一队列和同一 FSRS 卡片运行。
- 对没有释义的词，释义拼写与自测模式禁用该卡并显示可读提示；发音失败时保留当前卡片并允许重播或跳过。
- 文本导入使用严格 UTF-8；空文章或仅含空白行的文件在写入前拒绝，并显示具体问题。
- 文章逐句输入使用大小写不敏感比较；保存进度失败时停留在当前句并允许重试。

## 不在本轮范围

- 用户账号、跨设备云同步、在线翻译和远程文章库。
- 自定义音效主题、完整快捷键映射编辑器和多人/排行榜能力。
- 改写 FSRS 算法、把文章句子纳入 FSRS 计划或重算已有复习数据。

## 验收结果

1. 旧数据库升级后，原有词书、卡片、复习历史、活动队列和备份恢复继续可用。
2. 回忆、跟写、看义拼写、听写、自测五种模式共用当前 FSRS 队列；中断后恢复相同模式。
3. 错误输入会在一次事务中留下 Again 复习记录和错词标记；重复提交同一卡片不会产生第二条记录。
4. 收藏、错词和已掌握筛选可跨重启保留；取消已掌握后原 due 日期仍有效。
5. Articles 可以创建、导入、编辑、删除；用户能逐句跟写/听写、查看可选译文，并在重启后从保存位置继续。
6. 完整备份和旧版备份迁移都保留或兼容新增数据结构。
7. 解决方案 Release 构建成功；按计划逐项执行人工 UI 流程验收。

本轮 Release 构建已成功；词汇迁移/会话回滚验收和文章创建、编辑、进度恢复、迁移备份验收已通过 disposable harness。桌面窗口中的逐项 UI/键盘流程仍需运行应用后验收。
