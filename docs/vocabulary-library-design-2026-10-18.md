# Lexio 内置英语词书设计与实现记录

**状态：设计已获批准并已实现源码接入。** 常见词来源按许可核验结果从原先候选 BNC/COCA + FrequencyWords 调整为 wordfreq + FrequencyWords；BNC/COCA 的具体文件许可不能确认，因此没有打包。

## 用户目标

- Windows 版内置离线常见英语、大学学术和 IELTS 备考核心词书。
- 每条词有词性和普通话中文释义；首版不要求例句。
- 同一个词同时出现在多本词书时，保留各自的复习卡和进度。
- 安装或升级时只追加数据，不覆盖已存在释义，不重置卡片状态。
- 词条数据与应用代码使用各自许可；数据来源、版本、哈希及署名随发布包保留。

- `licenses/vocabulary/NOTICE.md` 记录 wordfreq、FrequencyWords、NGSL、NAWL 和 Wiktionary 来源、作者、条款及变更；`licenses/vocabulary/manifest.json` 记录固定版本、哈希、数量与覆盖率。
- 词包大小 3,885,950 字节，SHA-256 为 `466A0C617D36643335582B5D9FDCDF43FE721A38A90FE4DE04F3DC82C5C5EC40`。原始 Wiktionary 数据仅用于离线提取，未嵌入应用。

## 导入与数据安全

- `builtin-vocabulary.json` 作为 Core 嵌入资源随安装程序离线发布，不在运行时下载。
- `DictionaryService.EnsureBuiltInVocabularyAsync` 读取资源并计算 SHA-256；应用启动时在加载偏好设置前确保数据已导入。
- `AppDatabase.ImportBuiltInVocabularyAsync` 以一个 SQLite 事务写入三本词书、词条、释义、成员关系、缺失卡片和版本状态；已有 `settings` 表存版本，无 schema migration。
- 同一版本和哈希再次启动时不做写入；较旧版本不回退；相同版本换内容会失败并回滚。
- 对已有 lemma 采用不区分大小写匹配。只补空 IPA、词频、CEFR 等字段；相同 POS 与中文释义保留已有非空字段，其他新释义追加。词书关系只插入缺失项且不改旧 position；缺卡片才创建，因此已有卡片状态及复习日志不触碰。若某个普通用户词书已占用内置词书名称，会为内置词书使用“（Lexio 内置）”后缀并保存映射，避免启动失败或改写用户词书。
- 不修改 FSRS-6、Daily Planner 或 Learn 暂停/恢复逻辑。
